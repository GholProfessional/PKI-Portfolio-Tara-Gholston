Lab 1 Observations

1) Why the encrypted file is unreadable.
2) What would happen if the wrong password were used.
3) What security property symmetric encryption provides.
4) Why TLS uses symmetric encryption for data transfer.

1. The encrypted file is unreadable because Encryption represents Confidentiality so only authorized End Users are given access to open and read the data.  

2. When the wrong password is used, it will cause the End User to not be able to gain access to the data.  

3. The security that Symmetric Encryption provides a guarantee that data will be received by the internal authorized End User unless it is intercepted by an attacker. 

4. TLS uses Symmetric Encryption for data transfer (I think this is Data-in-Transit) because many internal End Users and devices (client(s) – server(s)) will be able to communicate/transmit data securely within a Company/Enterprise.
