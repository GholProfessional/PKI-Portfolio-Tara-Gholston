1. The Hash changed after a small change because the hexadecimal characters represent a certain count/amount which make up the length of the Hash Digest value. 

2. Hashing does not provide Confidentiality because the plaintext/readable data can be gained simply when any End User knows and matches the Hash Digest.  

3. The security that Hashing provides is the Integrity of data to know it has not be changed when sent/communicated or for authentication of devices on the Network. For instance, Code Signing uses Hashing because it ensures the application/software is reliable.  

4.  Where Hashing is used in PKI systems/devices are passwords, files, a part of the digital signatures.
